# Requerimientos e historias de usuario

| Archivo | Responsable |
|---|---|
| `requerimientos-funcionales.md` | Persona A |
| `requerimientos-no-funcionales.md` | Persona A |
| `historias-clientes-ventas.md` | Persona A |
| `historias-vehiculos-mantenimientos.md` | Persona B |

Formatos acordados:

- **RF**: `RF-01 — El sistema debe permitir registrar un cliente con…`
  (uno por requisito, con su módulo y el endpoint que lo cumple).
- **RNF**: medibles (`El endpoint GET /vehiculos responde en menos de…`,
  `Las contraseñas de la base no están en el repositorio`, etc.).
- **Historia de usuario**: `Como <rol>, quiero <acción>, para <beneficio>`
  + criterios de aceptación en formato *Dado / Cuando / Entonces*.
